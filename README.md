# Chunk Flashcards 🐣

한국어 → 영어 청크 암기용 플래시카드 앱.

## 사용법
- **어디서든 (핸드폰·셀룰러 OK)**: https://riwonn.github.io/flashcards/
  - sync.command를 실행하면 자동으로 최신 덱이 배포된다 (반영까지 1~2분)
  - 진행도는 기기·브라우저별로 따로 저장됨
1. **index.html 더블클릭** → 브라우저에서 열림 (인터넷 불필요)
2. 카드 수 고르고 **🔀 랜덤 믹스 시작**
3. 카드 클릭(또는 스페이스바) → 정답 확인 → ⭕ 외웠다 / ❌ 다시
   - 카드는 **누를 때마다 문제 ↔ 정답으로 계속 뒤집힌다**
   - **틴더 스타일 스와이프**: 정답을 한 번 본 뒤에는 (어느 면에서든) 오른쪽으로 밀면 ⭕ 외웠다, 왼쪽으로 밀면 ❌ 다시
   - 버튼: ⭕ / ❌ 그대로 사용 가능
   - 키보드: `Space` 뒤집기, `→` 외웠다, `←` 다시, `Z`/`Backspace` 직전 카드 취소
   - **↩ 취소**: 화면 오른쪽 위 버튼으로 방금 넘긴 카드를 되돌린다 (답 기록·XP도 원상복구, 직전 1장만)
   - 세션은 **한 사이클로 끝** — 각 카드는 한 번씩만 나온다
4. 결과 화면: 정답률 도넛 차트 + 소요 시간 + 외움/놓침 집계
   - 다시 연습 옵션: **남은 카드 이어서 / 놓친 카드만 다시 / 같은 카드 다시**

## 테마 세트 (맥락으로 외우기) — 퀴즐렛 방식
- 홈 화면의 **🎯 테마 세트**에서 비슷한 맥락의 카드 ~30장 세트를 골라 학습
- 카드마다 외움/못외움이 저장되고 (마지막 답 기준), 세트에 다시 들어가면 **못 외운 카드만** 나온다
- 홈 목록에 세트별 진행도 표시 (예: "15/30 외움", 다 외우면 "✅ 완료")
- 완료된 세트에 들어가면 처음부터 전체 복습이 시작된다
- 세트 구성: 힘든 감정 & 회복 / 성장 마인드 / 하루의 장면들 / 대화 연결 표현 /
  커리어·돈·사회 / 사람·성격·관계 / 미드 문장 ①② (전체 8세트, 모든 카드 포함)
- 세트 정의: `presets.json` — 새 카드 추가 후 세트 배정이 필요하면
  Claude에게 **"플래시카드 세트 업데이트"**라고 요청 (sync.command가 알려줌)

## 타이핑 테스트 (외운 문장 쓰기)
- 홈 화면의 **⌨️ 타이핑 테스트** 버튼 — 지금까지 외운 카드들을 대상으로 한다 (외운 카드가 없으면 비활성)
- 한국어를 보고 영어를 직접 입력 → Enter 또는 [확인]으로 채점
- 채점은 관대하게: 대소문자·문장부호 무시, 사소한 오타 허용, `/`로 나뉜 표현·예문 줄도 정답 인정
- 틀렸을 때 정답과 내 답이 비교 표시되고, 표현이 달랐을 뿐이면 **⭕ 맞은 걸로** 버튼으로 정정 가능
- 타이핑에서 틀린 카드는 다시 "못 외움"으로 바뀌어 테마 세트 복습에 다시 나온다
- 채점 후 Enter로 바로 다음 카드로 넘어간다

## 발음 듣기 (TTS)
- 카드 뒷면(영어)의 **🔊 발음 듣기** 버튼으로 발음을 들을 수 있다
- 우선순위: OpenAI AI 음성 (키 설정 시) → 무료 Google 음성 (기본값, 인터넷 필요) → 기기 내장 음성 (오프라인)
- **무료 (기본값)**: 아무 설정 없이 Google 번역 음성으로 재생된다
- **AI 음성 (선택)**: 홈 화면 [AI 음성 설정]에 OpenAI API 키(sk-…)를 넣으면
  더 자연스러운 신경망 음성(gpt-4o-mini-tts)으로 재생된다. 키는 브라우저에만 저장됨
- **맥 프리미엄 음성 (무료, 오프라인)**: 시스템 설정 → 손쉬운 사용 → 콘텐츠 말하기 →
  시스템 음성 → 관리에서 "Ava (Premium)" 등을 내려받으면 오프라인 폴백 품질이 좋아진다
- 같은 카드는 한 번 받아온 음성을 재사용해서 호출을 아낀다 (세션 동안)

## 예문 (이렇게 써요)
- 카드 뒷면의 영어 아래에 그 청크를 활용한 자연스러운 예문이 표시된다
- 예문 옆 🔊 버튼을 누르면 그 예문의 발음을 들려준다
- 예문 데이터: `examples.json` (카드 id → 예문 목록)
- chunk-bank에 새 카드를 추가한 뒤 예문이 비어 있으면
  Claude에게 **"플래시카드 예문 생성해줘"**라고 요청 (sync.command가 알려줌)

## chunk-bank.md 동기화
`Daily Note/chunk-bank.md`가 업데이트되면 **sync.command 더블클릭** (또는 `python3 sync.py`).
표 형식(직역 교정표 / 수업 어휘 / 표현 모음)을 자동으로 카드로 변환한다.

## CSV 추가
- 형식: `한국어,영어,메모` (메모는 생략 가능, 첫 줄 헤더 있어도 됨)
- 방법 A: 앱에서 **📄 CSV 가져오기** 버튼, 또는 **CSV 파일을 앱 화면에 드래그앤드랍** (브라우저에 저장됨)
- 가져오기가 성공하면 토스트로 추가된 장수를 알려주고,
  파일 이름으로 된 **테마 세트**(예: "📄 미드표현")가 자동 생성되어 홈에서 바로 학습할 수 있다
- 같은 파일을 다시 가져오면 새 행만 기존 세트에 합쳐진다
- 방법 B: CSV 파일을 `import/` 폴더에 넣고 sync.command 실행 (덱에 영구 반영)

## 게임 시스템
- 정답 +10 XP · 오답 +3 XP · 세션 완주 +20 XP
- 레벨업하면 캐릭터 진화: 🥚 → 🐣 → 🐥 → 🐤 → 🐦 → 🦜 → 🦉 → 🦅 → 🐉 (Lv.20)
- 🔥 연속 학습 스트릭, 3회 정답 시 카드 마스터

## 기기 간 동기화
- 진행도는 기기·브라우저별로 따로 저장되므로, 옮기려면 홈의 **🔄 기기 간 동기화** 사용
- 보내는 기기: [📤 코드 만들기] → 자동 복사된 코드를 카톡/메모 등으로 전달
- 받는 기기: 코드를 붙여넣고 [📥 가져오기]
- 기록은 덮어쓰지 않고 **병합**된다 — 카드마다 더 최근 기록 우선, XP는 큰 쪽 유지
- 가져온 CSV 카드·세트도 함께 옮겨진다

## 데이터 저장 위치
- 카드 덱: `index.html` 안에 내장 (sync.command가 자동으로 갱신)
- 진행도(XP·스트릭·카드별 기록): 브라우저 localStorage
  ⚠️ 항상 같은 브라우저로 열어야 진행도가 유지됨
